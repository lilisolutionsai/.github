# .github

Organization-wide defaults for [lilisolutionsai](https://github.com/lilisolutionsai).

Files here apply to every repository in the org that does not define its own equivalent.
This repository is public because GitHub only applies org-wide issue templates from a
public `.github` repository — keep it free of anything not meant to be world-readable.

## Contents

- `.github/ISSUE_TEMPLATE/developer-request.yml` — the Developer Request issue form.
- `.github/ISSUE_TEMPLATE/config.yml` — disables blank issues so requests go through the form.

A repository that adds its own `.github/ISSUE_TEMPLATE/` folder overrides these defaults entirely.
